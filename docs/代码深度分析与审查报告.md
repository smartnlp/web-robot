---

## 1. 项目概览

### 1.1 项目定位与功能
**事实描述**:
- 该项目是一个独立的 Web 智能客服机器人组件，可嵌入任意网页使用
- 核心功能包括：机器人对话、人工客服转接、图片上传、消息列表展示
- 提供完整的对话界面，包括消息气泡、输入框、功能菜单、客服状态指示

### 1.2 运行方式
**事实描述**:
- 纯静态页面，直接通过浏览器打开 `index.html` 即可运行
- 无工程化构建流程，无依赖安装过程
- 通过 `<script>` 标签直接引入 `robot/robot.js` 启动组件
- 组件自动向页面注入所需 CSS 样式

### 1.3 页面特性
**事实描述**:
- 支持移动端与桌面端适配
- 支持固定定位的悬浮对话窗口
- 支持最小化/最大化窗口
- 支持消息发送与接收动画效果

## 4. CSS 质量分析

### 4.1 样式架构与命名规范
**事实描述** (`robot/css/robot.css`):
- ✅ **采用 BEM 命名空间**: 所有类名统一使用 `smartnlp-robot-` 前缀，有效避免样式冲突
- ✅ **命名规范一致**: 使用连字符命名法（kebab-case），如 `.smartnlp-robot-header`
- ✅ **重置样式完备**: 组件内部包含完整的样式重置，隔离外部样式影响
- ❌ **缺少注释**: 无区块划分注释，功能模块边界不清晰

### 4.2 响应式适配评估
**事实描述**:
- ✅ 移动端适配：使用 `@media screen and (max-width: 767px)` 断点
- ✅ 针对设备特性做了优化：`-webkit-overflow-scrolling: touch` 启用硬件加速
- ✅ 适配 Retina 屏幕：提供 2x 图标
- ❌ 断点设计单一：仅支持 767px 一个断点，缺少平板尺寸过渡

### 4.3 嵌套层级与特异性
**事实描述**:
- 平均嵌套层级：2-3 层，符合最佳实践（建议 ≤ 4 层）
- 最高嵌套层级：4 层（如 `.smartnlp-robot-footer .smartnlp-robot-tools ul li a`）
- 特异性控制：通过前缀有效降低特异性冲突风险

### 4.4 冗余与兼容性
**事实描述**:
- ✅ 浏览器前缀完整：包含 `-webkit-`、`-moz-`、`-ms-` 前缀
- ✅ Box-sizing 规范：统一使用 `box-sizing: content-box`
- ❌ 存在 IE 浏览器兼容 hack：`border-width:1px \9`
- ❌ 存在大量重复属性定义：不同选择器定义相同属性值

### 4.5 性能问题
**事实描述**:
- 未使用 CSS 压缩（开发版）
- 存在大量可以合并的公共样式
- 未使用 CSS Sprites 技术整合图标

**可执行建议**:
1. 引入 CSS 压缩流程，减少文件体积
2. 抽离公共样式变量与混合宏，使用 LESS 特性

### 5.1 代码组织结构

### 5.5 网络请求管理
