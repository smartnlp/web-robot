聊天记录导出功能已完成

已成功为 web-robot 聊天机器人添加聊天记录导出功能，以下是实现说明：

功能特性：

  • 支持导出为 TXT 格式（便于阅读和打印）
  • 支持导出为 JSON 格式（便于程序处理）
  • 纯前端实现，使用 Blob 方式下载
  • 兼容主流浏览器（Chrome、Firefox、IE10+、Edge等）
  • 保持原有响应式设计，支持多端自适应

使用方法：

1. 点击聊天窗口右上角的「导出」图标
2. 选择导出格式（TXT 或 JSON）
3. 文件将自动下载到本地

导出文件格式说明：

TXT 格式内容：

聊天记录导出时间：2024-03-15 12:30:45
========================================

[12:30:00] 我
你好，请问有什么可以帮助您的？

[12:30:05] 智能客服
您好，很高兴为您服务！

========================================
共 2 条消息

JSON 格式内容：

{
  "exportTime": "2024-03-15 12:30:45",
  "total": 2,
  "robotName": "智能客服",
  "messages": [
    {
      "type": "user",
      "nick": "我",
      "time": "12:30:00",
      "text": "你好，请问有什么可以帮助您的？"
    }
  ]
}
